# 작업 흐름 — 영감 썸네일 1장 만들기

## 7문장
1. Threads에서 "BK의 영감 - N" 포스트를 열고 번호와 제목 문구를 확인한다.
2. 포스트의 원본 이미지를 내려받아 `영감N` 폴더에 저장한다.
3. Figma의 folders 템플릿을 복제해서 새 프레임(1200x630)을 만든다.
4. 제목 문구와 대표 이미지를 템플릿 자리에 넣는다.
5. 글자가 잘리거나 이미지가 어긋나지 않았는지 눈으로 확인한다.
6. 마음에 들면 PNG로 내보내 `영감N` 폴더에 넣는다.
7. 블로그 글에 썸네일을 올리고 작업 기록에 번호를 적는다.

## 멈칫하는 지점 (사람이 오래 고민하는 곳)
- **2번**: 포스트 이미지 중 어느 것이 대표 이미지인지 고르는 순간.
- **5번**: "충분히 깔끔한가"를 판단하는 순간. 기준이 눈대중이라 매번 흔들린다.

## 그냥 넘기는 지점 (기계에 맡겨도 되는 곳)
- **2번 저장**: 파일 내려받기와 폴더 정리.
- **3번 복제**: 템플릿 복제와 프레임 크기 설정.
- **6번 내보내기**: PNG 변환과 파일명 붙이기.

## 하네스로 옮길 때의 방향
- 5번의 "깔끔함"은 셀 수 있는 조건으로 바꾼다. 예: 프레임은 정확히 1200x630, 제목은 2줄 이하, 글자가 프레임 안에 100% 들어옴.
- 사람 승인은 6번 직전 한 곳에만 둔다.
