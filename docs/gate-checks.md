# 게이트 확인 방법

CLAUDE.md의 게이트 규칙을 "무엇으로 확인하는지"로 풀어 쓴다. 판정은 에이전트의 말이 아니라 이 확인 결과로 한다.

| 규칙 | 확인 방법 | 통과 조건 |
|---|---|---|
| 프레임 크기 | Figma 프레임의 width, height 값을 읽는다 | 1200 x 630 |
| 제목 줄 수 | 제목 텍스트 노드의 줄 수를 센다 | 2 이하 |
| 제목 잘림 | 텍스트 노드 영역이 프레임 영역 안에 있는지 비교한다 | 벗어남 0건 |
| 템플릿 | 복제 원본 이름을 확인한다 | folders 하나뿐 |
| 원본 이미지 | `영감N/` 폴더의 이미지 파일 수를 센다 | 1장 이상 |
| 이미지 벗어남 | 이미지 노드 영역이 프레임 영역 안에 있는지 비교한다 | 벗어남 0건 |
| 이미지 왜곡 | 이미지 노드 가로세로 비율과 원본 비율을 비교한다 | 같음 |
| 이미지 해상도 | 원본 파일의 가로 픽셀을 읽는다 | 1200 이상 |

## 실패했을 때
실패하면 2번(조립)으로 돌아간다. 같은 번호에서 3회 연속 실패하면 멈추고 사람에게 아래 내용을 알린다.

- 실패한 규칙 이름
- 시도 횟수
- 마지막 미리보기와 측정값(예: 줄 수 3, 프레임 밖으로 40px 벗어남)
