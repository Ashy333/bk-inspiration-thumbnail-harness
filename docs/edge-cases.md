# 예외 상황

| 상황 | 하는 일 | 하지 않는 일 |
|---|---|---|
| `영감N/`이 이미 있다 | 멈추고 사람에게 덮어쓸지 묻는다 | 묻지 않고 덮어쓰기 |
| 포스트에 이미지가 0장이다 | 수집 단계에서 멈추고 알린다 | 조립까지 진행하기 |
| 제목이 2줄을 넘는다 | 줄인 제목안을 2~3개 제시하고 사람이 고른다 | 에이전트가 제목을 바꿔서 통과시키기 |
| Threads 로그인이 필요하다 | 사람이 직접 로그인한다 | 자격 증명을 받거나 기록하기 |
| 같은 번호의 기록이 이미 있다 | 사람에게 다시 만들지 묻는다 | 중복으로 만들기 |
| 3회 연속 게이트 실패 | 멈추고 `docs/gate-checks.md`의 보고 내용을 알린다 | 규칙을 고쳐서 통과시키기 |
